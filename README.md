# hannahmartingeology.github.io

Hannah Martin's personal website, built with the Academic Pages template and hosted free on GitHub Pages.

Where things live:
- News & wins: `_data/news.yml` (add new items at the top)
- Fieldwork: `_fieldwork/`
- Talks & conferences: `_talks/`
- Publications: `_publications/`
- Outreach & media: `_outreach/`
- Blog posts: `_posts/`
- Photos: `images/` (replace a placeholder by uploading a photo with the same filename)
